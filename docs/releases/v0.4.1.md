## KAR READER 0.4.1 — development build

A new look: a **clean, modern blue theme** in light and dark mode. Everything else is as in 0.4.0
(English, Hindi and Hinglish transcription; Devanagari or Roman Hindi).

- Cool white and grey surfaces, primary blue, bright accent; dark mode on deep navy.
- Light top bars with blue actions; modern sans-serif headings (reading text keeps its serif).
- Content no longer runs under the status bar.

Screenshots taken on an Android emulator; not yet tried on a physical phone.

### Which file to download
- **KAR-READER-0.4.1.apk** — the standard, fully offline app. Start with this one.
- **KAR-READER-Sync-0.4.1.apk** — the same app plus direct Wi-Fi sync between your own devices.

### Installing over 0.3.x / 0.4.0
Releases are still signed with a one-off key, so uninstall the old version first
(**this deletes its data**: back up books and notes in Settings › Backup first; recordings aren't in backups yet).
